# Google Apps Script — връзка с календара

Този скрипт стои между сайта и Google Календар. Сайтът го пита кои часове са
заети и му праща новите резервации.

## Защо трябва да се обнови

Ако скриптът връща само **началния** час на събитие:

```json
{ "status": "success", "busySlots": ["09:00"] }
```

сайтът няма откъде да знае колко трае то и приема 60 минути. Затова
двучасов час, запазен в календара от 09:00 до 11:00, запушва само 09:00–10:00,
а 10:00 остава свободен за записване.

`Code.gs` в тази папка връща **начало и край**:

```json
{
  "status": "success",
  "date": "2026-09-09",
  "busySlots": [{ "start": "09:00", "end": "11:00", "title": "Боядисване — Мария" }]
}
```

Така сайтът блокира точното време — нито повече, нито по-малко.

## Инсталиране

1. Отворете [script.google.com](https://script.google.com) → **New project**.
2. Изтрийте примерния код и поставете съдържанието на `Code.gs`.
3. Горе вдясно **Project Settings** (зъбчатото колело) → **Time zone** →
   `Europe/Sofia`. Ако зоната е различна, часовете ще излизат разместени.
4. Ако ползвате отделен календар (не основния), сложете неговото id в
   `CALENDAR_ID`. Намира се в Календар → Настройки на календара →
   **Интеграция на календара** → *ID на календара*.
5. По избор: сложете id на Google Sheet в `SHEET_ID`, ако искате всяка
   резервация да влиза и в таблица. Id-то е частта между `/d/` и `/edit`
   в адреса на таблицата.
6. **Deploy** → **New deployment** → тип **Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
7. Копирайте получения адрес и го сложете в `js/config.js` →
   `CALENDAR_CONFIG.webAppUrl`.

При първото пускане Google ще поиска разрешение за календара — това е
нормално, скриптът работи от ваше име.

## Проверка

В редактора изберете функцията `testDoGet` и натиснете **Run**. В `Execution
log` ще видите точно какво връща скриптът за днешния ден. Ако там има събитие
с `start` и `end`, всичко е наред.

Отваряне и на адреса в браузър върши работа:

```
https://script.google.com/macros/s/ВАШИЯТ_ID/exec?date=2026-09-09
```

## След всяка промяна в кода

Apps Script не публикува промените автоматично. **Deploy** →
**Manage deployments** → молив (Edit) → *Version*: **New version** → **Deploy**.
Адресът остава същият.

## Какво получава скриптът при резервация

POST с тяло в JSON (`text/plain`, за да няма CORS preflight):

| Поле | Пример |
|---|---|
| `name`, `phone`, `email`, `notes` | данните от формата |
| `rawDate`, `rawTime` | `2026-09-09`, `14:30` |
| `duration` | `120` (минути) |
| `serviceName`, `categoryLabel` | `Боядисване на коса (при Мила Тодорова)`, `Коса` |
| `specialist`, `specialistId` | `Мила Тодорова`, `mila` |
| `price`, `code` | `120`, `L-ABC123` |

Събитието се създава с продължителността от `duration`, така че двучасова
услуга заема два часа в календара.
